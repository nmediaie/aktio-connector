Schema.org, robots.txt i llms.txt dla botów AI, Site Health i aktualizacje — do współpracy z Aktio.

== Description ==

Aktio Connector dodaje dane strukturalne schema.org, reguły dla botów AI w robots.txt oraz plik llms.txt. Wtyczka sama nie łączy się z Aktio i nie wysyła żadnych danych — ruch zawsze inicjuje Aktio przez REST API strony.
